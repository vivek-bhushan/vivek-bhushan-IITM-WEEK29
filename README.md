# Week 29 Project Package

**Project:** Reliable Retail Assistant — Text RAG + Multimodal RAG  
**Student:** Vivek Bhushan

## Summary
In Week 29, I developed a Reliable Retail Assistant using text-based and multimodal Retrieval-Augmented Generation (RAG), based on the provided `starter_code.ipynb` and aligned with the provided Project Template. The system uses a 31-product retail catalog, FAISS retrieval, grounded JSON recommendations, Pydantic validation, observability logs, multimodal processing of the provided `shoe.jpg`, a unified text/image controller, and a five-case evaluation harness with a 100% pass rate. The implementation was started from the provided `starter_code.ipynb` and organized according to the requirements in the provided Project Template.
